# Catálogo Digital & Generador de PDFs - Bebidas 25 de Mayo

Aplicación local unificada (sin necesidad de separar servidores ni configuraciones complejas) diseñada para negocios de venta y distribución de bebidas y alcohol.

---

## 🚀 Inicio Rápido

Para iniciar la aplicación simplemente haz **doble clic** en:
```
iniciar.bat
```
La aplicación se abrirá automáticamente en tu navegador web en:
👉 `http://127.0.0.1:5000`

---

## 📦 Características Principales

1. **Exportación a PDF en 1 Clic**:
   - **PDF Minorista**: Formato idéntico al PDF oficial de **Bebidas 25 de Mayo**, con cabecera negra, banner rojo institucional (*PARA TU NEGOCIO Y PARA VOS*), barras doradas por categoría y precios en rojo.
   - **PDF Mayorista**: Formato con precios de lista mayorista y escalas de descuento por volumen, disponible tanto en formato lista como en grilla de 6 tarjetas por página con fotos.
   - **Previsualizador integrado**: Puedes ver el PDF en pantalla antes de descargarlo.

2. **Gestión Total del Catálogo**:
   - Agregar, editar, duplicar y eliminar productos con su foto, categoría, presentación y precios.
   - Activar u ocultar productos del catálogo con un solo clic.
   - Búsqueda en tiempo real por nombre, presentación o categoría.

3. **Ajuste Masivo de Precios (%)**:
   - Aplica incrementos o descuentos porcentuales inmediatos a todo el catálogo o por categoría (ideal ante cambios de precios de proveedores o inflación).

4. **Configuración 100% Personalizable**:
   - Nombre del negocio / empresa.
   - Subtítulos para catálogo Minorista y Mayorista.
   - Frase destacada del banner rojo.
   - Textos de contacto, WhatsApp y redes sociales.
   - Cláusula legal / Disclaimer del pie de página.
   - Carga de nuevo Logo corporativo.
   - Selección de colores y escalas de descuento por volumen.

5. **Copia de Seguridad y Excel**:
   - Exporta todo el inventario a un archivo `.CSV` compatible con Microsoft Excel.
   - Importa listas completas de productos desde Excel en segundos.

---

## 🛠️ Requisitos Técnicos
- Windows 10/11 con Python 3.10 o superior (instalado).
- Las librerías necesarias se instalan automáticamente al iniciar `iniciar.bat`.
